# 📊 Customer Churn Prediction

Predicting which telecom customers are likely to leave (Churn) using Machine Learning - to help companies retain customers.

**GitHub:** https://github.com/MaryadaMahalaxmi/customer-churn-prediction
**Deployed Model:** Random Forest Classifier (85% Accuracy)

### 🚀 Problem Statement
Telecom companies lose revenue when customers churn. This project predicts churn in advance so the company can offer retention plans.
